# Импорт из Steam

В «Досуг → Игры» нажми «Синхронизировать Steam». Импортируются только игры, где суммарное время **строго больше 300 минут**; ровно 5 часов не проходят фильтр. Учитываются и бесплатные игры, в которые ты играл. В карточках отображаются часы и минуты Steam отдельно от ручного процента прохождения: часы не определяют, пройдена ли игра.

## Подключение

1. Войди в свой Steam на https://steamcommunity.com/dev/apikey и зарегистрируй Web API-ключ. Если требуется домен, укажи домен своего приложения.
2. На сервере добавь секретную переменную окружения `STEAM_API_KEY`. На Render: сервис → Environment → Add Environment Variable → Save, rebuild, and deploy. Не добавляй значение в Git или клиентский код.
3. Для этого приложения по умолчанию используется SteamID64 `76561198800622628` — https://steamcommunity.com/id/R1ch11/. Для другого профиля задай `STEAM_ID` (17 цифр) в окружении сервера.
4. В Steam: профиль → редактировать профиль → приватность → «Доступ к игровой информации» → «Открытый». Отключи настройку, скрывающую общее время в играх.
5. После перезапуска сервера открой «Досуг → Игры» и нажми кнопку синхронизации.

Для локального запуска те же переменные можно указать в `.env` в корне проекта (этот файл исключён из Git).

## Поведение

- Повторная синхронизация обновляет часы по Steam AppID и профилю, без дублей. Вручную добавленная игра с единственным точным совпадением названия привязывается к Steam.
- Оценки, заметки, названия, статусы и ручной прогресс существующих записей сохраняются. Новые импортированные игры получают статус «В процессе».
- Другие записи не удаляются, даже если Steam перестал возвращать игру. Удалённая вручную импортированная игра снова попадёт в коллекцию при следующей синхронизации, если соответствует фильтру.
- Если библиотека скрыта, ключ не задан или Steam недоступен, приложение показывает ошибку и сохраняет коллекцию. Нулевой результат импорта не очищает существующие записи.
- Ключ используется только сервером для библиотеки и достижений; в клиентские ответы он не попадает.

Документация Valve: https://partner.steamgames.com/doc/webapi/IPlayerService#GetOwnedGames.

## Обложки и достижения

В играх появился отдельный вид с обложками, последней активностью, часами, поиском и сортировкой. Карточка открывает описание магазина, жанры, разработчика, скриншоты и список достижений с фильтрами. Первые 12 видимых игр постепенно обогащаются данными, максимум по две одновременно. Описание и схемы достижений кешируются на час, личные достижения — на 5 минут.

Обложки и описание доступны без ключа. Для личных достижений нужен STEAM_API_KEY и открытая статистика профиля. Недоступные достижения показываются как недоступные, а не как нулевой прогресс. Процент достижений отделён от ручного процента прохождения. API не раскрывает названия и описания скрытых неполученных достижений.

## Обложки игр из других магазинов

У ручной записи можно найти обложку по названию в публичном каталоге Steam или загрузить JPG, PNG, WebP с устройства (до 10 МБ). Выбор картинки не импортирует игру и не привязывает её к Steam-профилю. Если игры нет в каталоге Steam, используется своя картинка или декоративная заглушка.

Загружаемые изображения уменьшаются до 720×400, сервер сохраняет их как компактный WebP (до 55 КБ) внутри записи, вместе с локальным и облачным сохранением. Повторное редактирование не сжимает такую обложку заново. Свою картинку можно заменить или удалить; у импортированной игры после удаления своей картинки снова показывается обложка Steam.
