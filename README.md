# Hevy AI Coach & Analytics 🏋️‍♂️

Установка веб-приложения на iPhone и push-уведомления: [инструкция Web Push](WEB_PUSH.md).

Персональный ИИ-тренер и система спортивной аналитики на базе официального **Hevy API**.

## Возможности
1. **Синхронизация с Hevy API**: Загрузка тренировок, программ (routines) и шаблонов упражнений.
2. **Анализ прогрессивной перегрузки (Progressive Overload)**: Отслеживание динамики рабочих весов, повторений, тоннажа и расчетного 1RM (формула Эпли).
3. **Оценка баланса нагрузок**: Анализ тоннажа по мышечным группам (спина, грудь, ноги, плечи, руки, кор) и предупреждение дисбалансов.
4. **Контроль кардио**: Анализ бега (дистанция, время, темп мин/км, скорость км/ч) и его влияния на восстановление после силовых нагрузок.
5. **Подготовка к следующей тренировке**: Автоматическое определение следующего дня сплита и постановка точных целевых ориентиров по весам на основе предыдущих тренировок.

## Быстрый запуск

### 1. Веб-приложение для телефона:
```powershell
python bot.py
```
`bot.py` — совместимый загрузчик веб-приложения. Telegram-клиент, обработчики сообщений и рассылки удалены. Сервер запускает FastAPI и фоновые задачи приложения без Telegram-токена.

Вечерний отчёт сохраняется в чате AI-тренера по расписанию (по умолчанию 23:00 по Омску), затем отправляется Web Push. Для бесплатного Render подключён внешний запуск через GitHub Actions; подробности — в [WEB_PUSH.md](WEB_PUSH.md).

### 2. Консольные команды (CLI):
```powershell
# Перейти в директорию
cd C:\Users\cfyz1\.gemini\antigravity\scratch\hevy_coach

# Разбор последней тренировки
python coach.py last

# Подготовка к следующей тренировке
python coach.py next

# Дневник питания из YAZIO
python coach.py nutrition

# Профиль спортсмена и биометрия
python coach.py profile

# Общая сводка и распределение объема
python coach.py weekly

# Отслеживание динамики по конкретному упражнению
python coach.py prog -e "тяга"

# Синхронизация свежих тренировок из Hevy
python coach.py sync
```

## Структура проекта
- `config.py` — загрузка конфигурации и API ключа из `.env`.
- `hevy_client.py` — клиент Hevy API с авто-повторами, таймаутами и обработкой пагинации.
- `storage.py` — локальное кэширование тренировок и программ.
- `analyzer.py` — аналитический движок (расчет тоннажа, 1RM, мышечных групп, кардио).
- `coach.py` — персональный ИИ-тренер и CLI.
- `test_coach.py` — модульные тесты всей системы.

## Досуг в приложении

Вкладка «Досуг» заменяет «Зал»: игры, фильмы, сериалы и аниме. Можно вести планы, отмечать прогресс (проценты в играх и серии в сериалах/аниме), завершение, оценки и заметки. Данные сохраняются в `data/media.json` и в Upstash при его настройке; браузер хранит копию для просмотра. После восстановления связи доступно редактирование. Книги остаются отдельной вкладкой, данные Hevy продолжают использоваться в обзоре, недельных отчётах и боте.

Импорт игр из Steam с временем больше 5 часов: [подключение и настройки](STEAM.md).


### Сохранность коллекции «Досуг»

Используется то же подключение Upstash Redis, что для книг: `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`. Книги хранятся под `athlete_books`, досуг — под `athlete_media`. После деплоя коллекция загружается из Redis; локальный `data/media.json` служит копией. При настроенном Upstash ошибка чтения не заменяется пустой коллекцией, ошибка записи возвращает 503 и не подтверждает изменение в интерфейсе. Сбой локального диска после подтверждённой записи Redis не отменяет сохранённые данные.

Вверху вкладки есть «Проверить» для живого чтения из Upstash без вывода ключей, а также «Скачать копию» и «Восстановить». Восстановление заменяет всю коллекцию «Досуг» после подтверждения и проверки файла, сохраняя Steam-поля, обложки, оценки и заметки. Можно импортировать отдельную копию с полем `items` или общую с полем `media`. Общие `/api/backup` и `/api/restore` теперь тоже включают `media`; прежние копии только с книгами и привычками остаются совместимыми.

Без переменных Upstash приложение работает локально и показывает предупреждение: файлы временного сервера Render не заменяют внешнюю базу. Наличие настройки и ответ базы — разные проверки: статус «Upstash отвечает» появляется только после успешного запроса по кнопке. Изменения схемы не требуют новой базы или нового ключа.
