# Hevy AI Coach & Analytics 🏋️‍♂️

Персональный ИИ-тренер и система спортивной аналитики на базе официального **Hevy API**.

## Возможности
1. **Синхронизация с Hevy API**: Загрузка тренировок, программ (routines) и шаблонов упражнений.
2. **Анализ прогрессивной перегрузки (Progressive Overload)**: Отслеживание динамики рабочих весов, повторений, тоннажа и расчетного 1RM (формула Эпли).
3. **Оценка баланса нагрузок**: Анализ тоннажа по мышечным группам (спина, грудь, ноги, плечи, руки, кор) и предупреждение дисбалансов.
4. **Контроль кардио**: Анализ бега (дистанция, время, темп мин/км, скорость км/ч) и его влияния на восстановление после силовых нагрузок.
5. **Подготовка к следующей тренировке**: Автоматическое определение следующего дня сплита и постановка точных целевых ориентиров по весам на основе предыдущих тренировок.

## Быстрый запуск

### 1. Персональный Telegram-бот (для телефона):
```powershell
# Запуск бота (или двойной клик по run_bot.bat)
python bot.py
```
После запуска бот работает на вашем телефоне в Telegram с удобными кнопками:
- 🏋️ Последняя тренировка
- 📋 План на сегодня
- 🥗 Питание за день из YAZIO
- 📈 Недельный отчет
- 👤 Профиль и вес

### 2. Консольные команды (CLI):
```powershell
# Перейти в директорию
cd C:\Users\cfyz1\.gemini\antigravity\scratch\hevy_coach

# Разбор последней тренировки
python coach.py last

# Подготовка к следующей тренировке
python coach.py next

# Дневник питания из YAZIO
python coach.py nutrition

# Профиль спортсмена и биометрия
python coach.py profile

# Общая сводка и распределение объема
python coach.py weekly

# Отслеживание динамики по конкретному упражнению
python coach.py prog -e "тяга"

# Синхронизация свежих тренировок из Hevy
python coach.py sync
```

## Структура проекта
- `config.py` — загрузка конфигурации и API ключа из `.env`.
- `hevy_client.py` — клиент Hevy API с авто-повторами, таймаутами и обработкой пагинации.
- `storage.py` — локальное кэширование тренировок и программ.
- `analyzer.py` — аналитический движок (расчет тоннажа, 1RM, мышечных групп, кардио).
- `coach.py` — персональный ИИ-тренер и CLI.
- `test_coach.py` — модульные тесты всей системы.
