Вес и прогресс до цели

Новый прямоугольный виджет: вес + три последних уведомления →

Текущий вес, сколько уже сброшено и сколько осталось до 80 кг. Данные из того же импорта Apple «Здоровье».

  1. Установи Scriptable.
  2. Нажми кнопку ниже. Открой Scriptable → +, вставь скрипт в пустой редактор. Назови его FitPulse Weight.
  3. Нажми ▶ и введи свой HEALTH_IMPORT_TOKEN из Render. Используй тот же ключ, что для сна; без слова Bearer. Появится предпросмотр.
  4. На главном экране iPhone удерживай пустое место → добавь виджет Scriptable среднего размера.
  5. Удерживай виджет → Изменить виджет → Script: FitPulse Weight. В When Interacting выбери Open URL. В поле URL вставь https://fitness-bot-9f8m.onrender.com/?tab=weekly. Поле Parameter оставь пустым.
