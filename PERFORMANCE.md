# Быстрое открытие главного экрана

- Матрица привычек перенесена сразу под шапку, выше процентов и графиков.
- `/api/habits` читает сохранённые отметки без запросов к Hevy/YAZIO. Автоматическая синхронизация остаётся в `/api/dashboard`, `/api/sync` и существующих фоновых задачах. После ответа dashboard клиент перечитывает обновлённые отметки.
- Последний подтверждённый ответ с привычками и dashboard сохраняется на устройстве и отображается при повторном открытии до ответа сервера. Кеш действует только в пределах текущего дня UTC+6; вчерашнее питание не подставляется за сегодня. Недоступное хранилище не мешает обычной загрузке.
- Время данных и статус обновления отображаются перед карточками статистики. Кеш ускоряет показ последних данных, но не делает внешние API быстрее. Первое открытие и первый вход после полуночи могут ждать свежего питания.
- Тренировки, недельный отчёт и книги загружаются при открытии соответствующей вкладки, вместо трёх дополнительных запросов при каждом запуске.
- Долгая автоматическая синхронизация не перезаписывает ручные изменения, сделанные во время её выполнения. При конкурентном изменении автоматические отметки применятся в следующий цикл. Локальный файл привычек заменяется атомарно; операции записи сериализованы для одного процесса.

Проверка: `python -m unittest test_push test_dashboard_loading -v`, а в `frontend/` — `npm test` и `npm run build`.

Для Render обновить ветку сервиса на `perf/fast-dashboard` либо слить её в основную и задеплоить. Обновлённый `frontend/dist` включён в ветку. Первый успешный запрос заполнит кеш на iPhone; затем закрыть и снова открыть установленное приложение для проверки повторной загрузки.
