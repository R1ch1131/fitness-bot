# Каталоги книг, фильмов, сериалов и аниме

## Что подключено

- Книги: Open Library. Поиск по названию, автор, обложка; после выбора — издательство, дата издания, описание и число страниц, если каталог их сообщает. В поиске предпочтение русскому языку, но каталог может вернуть иностранное издание. Всегда проверь выбранное издание и страницы. API-ключ не нужен.
- Аниме: Shikimori. Русское и оригинальное название, постер, описание, жанры, студия, длительность серии, число серий и рейтинг каталога. Неизвестное число серий остаётся пустым. API-ключ не нужен.
- Фильмы и сериалы: TMDB. Названия на русском при наличии перевода, постер, описание, жанры, год, рейтинг; длительность фильма, число сезонов и серий. Требуется серверный токен.

Рейтинг каталога показан отдельно от личной оценки. Поиск не меняет заметки и просмотренный/прочитанный прогресс. Для сериалов и аниме кнопка «+1 серия» сохраняет прогресс; достижение известного общего числа завершает запись. Число серий — снимок каталога в момент выбора: для выходящих тайтлов его можно изменить вручную или повторно выбрать тайтл.

Сведения и обложки сохраняются в существующих записях books/media и их резервных копиях. Старым записям ничего не назначается автоматически: открой редактирование, найди название и выбери результат. Если обложка отсутствует или не загрузилась, отображается заглушка; доступна загрузка своей картинки.

## Подключить TMDB на Render

1. Зарегистрируйся или войди на https://www.themoviedb.org/.
2. Открой https://www.themoviedb.org/settings/api и оформи доступ к API для личного некоммерческого приложения. Сервис может запросить сведения о приложении: укажи реальные данные своего проекта.
3. В разделе API скопируй **API Read Access Token** (длинный токен). Нужен именно токен чтения, не короткий API Key.
4. В панели Render открой сервис fitness-bot → Environment → Add Environment Variable:
   - Key: `TMDB_READ_TOKEN`
   - Value: скопированный токен.
5. Сохрани настройки и перезапусти/переразверни сервис.
6. В «Досуг» → «Фильмы» или «Сериалы» → «Добавить» введи название и нажми «Найти по названию».

Для локального запуска задай ту же переменную окружения процессу сервера и перезапусти его. В локальном превью тоже нужен перезапуск сервера превью после добавления переменной.

Токен используется только сервером в заголовке Authorization. Не добавляй его в исходники, VITE-переменные или браузерный код. Без токена форма объясняет, что поиск ещё не подключён; ручное добавление и своя обложка работают.

## Технические детали

`GET /api/catalog/search?kind=book|movie|series|anime&title=...`
`GET /api/catalog/details?kind=...&external_id=...`

Запросы выполняются только по действию пользователя. Кэш до часа, максимум 128 ответов, интервал между запросами к одному источнику не меньше 1,05 секунды. При сбое каталогов форма сохраняет введённые данные. Данные каталогов не исполняются как HTML. Локальный предпросмотр использует живой поиск и временную демонстрационную коллекцию.

Источники и документация:
- https://openlibrary.org/dev/docs/api/search
- https://shikimori.one/api/doc
- https://developer.themoviedb.org/docs/authentication-application
- https://developer.themoviedb.org/docs/faq

В интерфейсе есть блок с логотипом и указанием источника TMDB: This product uses the TMDB API but is not endorsed or certified by TMDB.

## Запасные постеры аниме

При выборе аниме без картинки Shikimori сервер ищет постер в TMDB тем же `TMDB_READ_TOKEN`. Он использует русское и оригинальное название, тип произведения (фильм или сериал) и год выхода. Игровые экранизации исключаются по отсутствию жанра Animation. Только единственное точное совпадение названия и года выбирается автоматически. При неоднозначности пользователь видит варианты с названием и годом.

Для существующей записи: «Редактировать» → «Найти постер в TMDB» → «Сохранить». Это также позволяет заменить картинку, которая перестала загружаться. Меняется только обложка и её источник, личные заметки, оценка, название и прогресс сохраняются. В карточке указаны отдельно источник сведений Shikimori и источник постера TMDB.

Без токена или при ошибке TMDB основные сведения об аниме остаются доступными, а форма объясняет причину. Токен из Render не появляется автоматически в локальном превью: локальный сервер требует свою переменную окружения и перезапуск. Постеры в сохранённых записях не меняются сами при каждом открытии коллекции.
